Raw data

Drop dma0.bin, dma1.bin and meta.json of one run here, or .
Nothing is uploaded anywhere: decoding, pulse processing and ROOT writing all happen in your browser. Files are streamed from disk, so multi-GB runs work: only the frame headers and the per-frame results are kept in memory.

Workflow

  1. Data: load the DMA files of a run; the files are scanned once for their frame headers (disk speed, a few seconds per GB).
  2. Time: drag horizontally on the count-rate plot to select the time range of interest (e.g. beam on), then Process window.
  3. Waveform: drag the short/long gate bands and the threshold line, then Apply and process.
  4. PSD: set the n/γ cut on the PSD–energy map by dragging the red line or taking it from the fit.
  5. Save: build the ROOT files and download them.

Counts

Energy-dependent cut Two-Gaussian fits in logarithmic energy slices over the whole energy range of the selected channel/view; cut(E) = a + b/√E + c/E through the accepted slices. A slice is accepted when the two peaks pass the FoM threshold, two Gaussians improve χ² clearly over one, both peaks lie inside the PSD range and are not too wide, and the minority component holds at least 3 % and 50 events; at least three contiguous slices are needed. Below the first accepted slice events are not classified (counted as gamma); above the last the curve is held constant.

Reading it (ROOT)

TFile f("DataR_CH0@NOVO_33_run.root");
TTree* t = (TTree*)f.Get("Data_R");
UShort_t ch, board, en, es; ULong64_t ts; UInt_t fl;
t->SetBranchAddress("Channel", &ch);  t->SetBranchAddress("Timestamp", &ts);
t->SetBranchAddress("Energy", &en);   t->SetBranchAddress("EnergyShort", &es);
t->SetBranchAddress("Flags", &fl);
for (Long64_t i = 0; i < t->GetEntries(); i++) {
  t->GetEntry(i);
  double psd = en ? double(en - es) / en : 0;   // (Q_long - Q_short) / Q_long
}
t->Draw("(Energy-EnergyShort)/Energy:Energy", "!(Flags&4)", "colz");

The layout follows CAEN CoMPASS (trees Data_R / Data_F, same branch names and types), so analysis macros written for CoMPASS read these files unchanged. settings.json (gates, threshold, cut, filters, flag definitions) and run.info are written next to the files. For waveforms: TArrayS* s = nullptr; t->SetBranchAddress("Samples", &s);
